# Template to HTML (Figma Plugin)

마케팅팀이 Figma 템플릿에서 **텍스트만 수정**하고 **카드 개수를 자유롭게 조정**한 뒤,
완성된 디자인을 지정된 HTML 구조로 변환해주는 플러그인입니다. 이미지는 실제 파일로
바꾸지 않고 "자리 표시"만 남기며, 이후 카페24 등 다른 에디터에 붙여넣어 이미지를 직접 넣는
방식을 전제로 합니다.

## 전체 워크플로우

1. **디자이너**가 Figma에 마스터 템플릿을 만든다.
   - 타이틀/본문 텍스트 레이어
   - 이미지 자리를 나타내는 레이어(사각형/프레임 등, 실제 이미지가 있어도 무시됨)
   - (선택) 개수를 조정할 수 있는 **반복 그룹** — 예: 혜택 카드 3~5개, 이용 단계 2~4개 등
     여러 개의 반복 그룹을 한 템플릿에 넣을 수 있음
2. 템플릿을 복사해서 **마케팅팀에게 전달**한다.
3. 마케팅팀은 텍스트만 수정하고, 반복 그룹 안의 카드를 Figma에서 직접 복제(⌘/Ctrl+D)하거나
   삭제해서 **개수를 조정**한다. 이미지는 그대로 둔다.
4. 완성된 프레임을 선택하고 플러그인을 실행 → 이 README의 HTML 틀(또는 직접 준비한 틀)에
   맞춰 결과 HTML이 생성된다. 이미지 자리에는 "이미지 자리입니다"라는 표시만 채워진다.
5. 결과 HTML을 **카페24** 상세페이지 편집기의 "HTML 편집" 모드에 붙여넣고, 이미지 자리에는
   직접 이미지를 업로드해서 교체한다.

## 설치 (개발 모드로 불러오기)

1. Figma 데스크톱 앱에서 **Plugins → Development → Import plugin from manifest…** 선택
2. 이 폴더의 `manifest.json` 선택
3. 좌측 메뉴 **Plugins → Development → Template to HTML** 실행

빌드 과정 없이 순수 JS/HTML로만 구성되어 있어 바로 사용할 수 있습니다.

## 사용 방법

1. 캔버스에서 완성된 템플릿 프레임(또는 그룹)을 선택합니다. (여러 개 선택하면 각각 변환됩니다.)
2. 플러그인 UI에 원하는 HTML 틀을 붙여넣습니다(기본 예시가 이미 채워져 있습니다).
3. **"Figma에서 변환하기"** 클릭
4. 결과 HTML을 복사하거나 `.html` 파일로 다운로드해서 카페24 등에 붙여넣습니다.

## Figma 쪽 레이어 규칙

선택한 프레임의 하위 레이어를 이름으로 검색해 역할을 추정합니다(대소문자 무시, 부분 일치).

| 역할 | 인식 키워드 |
|------|-------------|
| Title | `title`, `headline`, `heading`, `제목`, `타이틀` |
| Body | `body`, `content`, `description`, `copy`, `text`, `본문`, `내용`, `설명` |
| Image | `image`, `photo`, `picture`, `thumbnail`, `img`, `이미지`, `사진` |

- Title/Body는 **텍스트 레이어**여야 실제 텍스트를 추출합니다.
- Image는 어떤 레이어 타입이든 상관없이 **크기(가로/세로)만** 읽습니다. 실제 픽셀은
  내보내지 않습니다.
- 검색은 프레임 최상단부터 하위 방향으로 진행되며, 이미 다른 역할로 매칭된 레이어는 제외됩니다.
- 가장 안전한 방법은 레이어 이름을 `Title`, `Body`, `Image`로 정확히 짓는 것입니다.

### 반복 그룹 (하나의 템플릿에 여러 개 가능)

한 템플릿 안에 서로 다른 반복 리스트가 **여러 개** 있을 수 있습니다(예: "혜택 카드" +
"이용 단계"). 각 반복 그룹은 이름으로 구분되는 **키**를 가지며, 이 키로 HTML의
`data-figma-repeat="<키>"` 와 매칭됩니다.

레이어 이름 짓는 법:

| 레이어 이름 예시 | 매칭되는 키 |
|------------------|-------------|
| `Items`, `List`, `카드`, `반복`, `목록`, `리스트` (키워드만 단독으로) | `items` (기본값) |
| `Repeat: Benefits` | `benefits` |
| `반복: 스텝` | `스텝` |
| `List-steps` | `steps` |

즉 `Repeat:`(또는 `반복:`/`List:`) 뒤에 원하는 이름을 붙이면 그 이름이 그대로 키가 됩니다.
템플릿에 반복 그룹이 하나뿐이면 그냥 `Items`처럼 단독 키워드만 써도 됩니다.

- 각 반복 그룹의 **직계 자식 레이어 각각이 하나의 "아이템"** 이 됩니다. 아이템 개수는
  마케팅팀이 Figma에서 늘리거나 줄인 그대로 반영됩니다.
  - 아이템이 텍스트 레이어 하나라면 → 그 텍스트가 아이템의 title이 됩니다.
  - 아이템이 프레임/그룹이라면 → 그 안에서 다시 title/body/image 키워드로 검색합니다.
  - 아이템 안에서 아무 것도 못 찾으면 → 아이템 전체를 이미지로 간주합니다(사진 한 장짜리 카드).
- 반복 그룹 안에 또 다른 반복 그룹을 넣는 **중첩 구조는 지원하지 않습니다.**

## HTML 틀 작성 규칙

### 기본 슬롯

```html
<img  data-figma-slot="image" src="" alt="" />
<h1   data-figma-slot="title"></h1>
<div  data-figma-slot="body"></div>
```

- `title` : 텍스트로 채워집니다.
- `body`  : 내용으로 채워집니다(줄바꿈은 `<br>`로 변환).
- `title`/`body` 안에서 **부분적으로 크기나 색이 다른 텍스트**(예: 본문 중 일부만 크게/빨갛게)도
  그대로 반영됩니다. 자세한 내용은 아래 "텍스트 크기·색상" 항목 참고.
- `image` : **실제 이미지 대신 자리표시(placeholder)** 가 채워집니다.
  - `<img>` 태그면 `src`에 "이미지 자리입니다 + 가로×세로" 글자가 그려진 회색 박스(SVG)가
    들어가고, `width`/`height` 속성이 Figma 레이어 크기로 채워집니다.
  - 다른 태그(예: `<div>`)면 텍스트로 "이미지 자리입니다"가 채워지고 같은 placeholder가
    배경 이미지로 채워집니다.
  - 이후 카페24 등에서 이 자리를 클릭해 실제 이미지로 교체하면 됩니다.

세 슬롯 모두 선택이며, 틀에 없는 슬롯은 그냥 무시됩니다.

### 반복 그룹 슬롯

개수가 가변적인 카드/리스트를 만들려면 `data-figma-repeat="<키>"`를 쓰고, 그 **바로 안에
아이템 템플릿 1개만** 넣습니다. 변환 시 이 아이템 템플릿이 Figma에서 찾은 개수만큼 복제됩니다.
`<키>`는 Figma의 반복 그룹 레이어 이름에서 나온 키와 **대소문자 무시하고 정확히 일치**해야
합니다(위 "반복 그룹" 표 참고).

```html
<!-- Figma 레이어 이름: "Repeat: Benefits" -->
<div data-figma-repeat="benefits">
  <div class="item">
    <img data-figma-slot="image" src="" alt="" />
    <h3 data-figma-slot="title"></h3>
    <p  data-figma-slot="body"></p>
  </div>
</div>

<!-- Figma 레이어 이름: "Repeat: Steps" -->
<ol data-figma-repeat="steps">
  <li>
    <h4 data-figma-slot="title"></h4>
    <p  data-figma-slot="body"></p>
  </li>
</ol>
```

- 아이템 템플릿 안의 `data-figma-slot`은 최상위 슬롯이나 다른 반복 그룹과 이름이 같아도
  됩니다(서로 겹치지 않고 각자의 영역에만 채워집니다).
- 반복 그룹이 **하나뿐**이면 값 없이 `data-figma-repeat`만 써도 됩니다(Figma에서 찾은 유일한
  그룹과 자동으로 매칭됩니다).
- 반복 그룹 안에 또 다른 반복 그룹을 넣는 **중첩 구조는 지원하지 않습니다.**

### 텍스트 크기·색상 (한 텍스트 레이어 안에서 부분적으로 다르게 쓴 경우)

Figma의 Title/Body 텍스트 레이어 안에서 일부 글자만 크기나 색을 다르게 준 경우, 그 부분별
스타일이 그대로 반영됩니다.

- **색상**은 Figma에 있는 실제 값을 그대로 가져옵니다(별도 설정 불필요).
- **크기**는 플러그인 UI 상단의 "허용할 폰트 크기" 입력창에 적어둔 값들 중 **가장 가까운
  값으로 자동으로 맞춰집니다**. 예를 들어 허용 목록이 `14,16,20,24,32,40`이고 Figma에서 실제
  크기가 22px이었다면, 결과 HTML에는 20px로 나갑니다. 즉 Figma에서 디자이너가 뭘 쓰든 최종
  결과물은 정해둔 크기 체계 안에서만 나오게 됩니다.
- 결과 HTML에는 인라인 `style="..."` 대신, 사용된 크기/색상 조합마다 클래스(`fx-1`, `fx-2`, ...)를
  만들고 그 규칙들을 모아 **문서 맨 위(`<head>` 최상단)에 `<style>` 블록 하나**로 넣습니다.
  ```html
  <head>
    <style>
      .fx-1{font-size:20px;color:rgb(0,0,0)}
      .fx-2{font-size:14px;color:rgb(51,51,51)}
    </style>
    ...
  </head>
  ...
  <h1 data-figma-slot="title"><span class="fx-1">메인 타이틀</span></h1>
  ```

## 카페24에 붙여넣을 때 참고

- 카페24 상세페이지 편집기의 "HTML 편집기" 모드에 결과 코드를 그대로 붙여넣으면 됩니다.
- 일부 에디터/게시판은 `<style>` 태그나 외부 CSS를 제거할 수 있습니다. 이 경우 위에서 설명한
  텍스트 크기/색상 클래스가 통째로 사라질 수 있으니, 붙여넣은 뒤 미리보기로 한번 확인해보세요.
  (제거된다면 클래스 기반 대신 인라인 스타일 방식으로 바꿔드릴 수 있습니다.)
- 이미지 자리(회색 placeholder)를 찾아 실제 상품 이미지로 교체하세요.

## 제한 사항 / 향후 개선 아이디어

- 반복 그룹은 여러 개 지원하지만, 중첩(반복 그룹 안에 반복 그룹)은 지원하지 않습니다.
- 아이템 내부 구조는 title/body/image 조합만 지원합니다(더 복잡한 카드는 추가 확장 필요).
- 이미지 자리표시는 회색 SVG 박스입니다. 브랜드 색상이나 문구를 바꾸고 싶으면 `ui.html`의
  `placeholderImageDataUri` 함수를 수정하면 됩니다.
