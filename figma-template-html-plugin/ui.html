Figma에서 Title / Body / (반복 가능한) 카드 그룹 / 이미지 자리를 포함한 프레임을 선택한 뒤, 아래 HTML 틀을 채우고 "Figma에서 변환하기"를 누르세요.
· 레이어 이름에 title/body(content)/image가 포함되면 자동 인식됩니다.
· Items, List 같은 그룹 레이어는 "반복 그룹"으로 인식되고 그 안의 자식 레이어 개수만큼(마케팅팀이 복제/삭제한 그대로) HTML도 반복 생성됩니다. 템플릿 하나에 여러 개의 반복 그룹이 있다면 Repeat: Benefits, Repeat: Steps처럼 이름을 지어 구분하세요 (HTML 쪽은 data-figma-repeat="benefits").
· 이미지는 실제 파일로 변환되지 않고 "이미지 자리입니다" 자리표시(placeholder)만 채워집니다. 완성된 HTML을 다른 에디터(예: 카페24)에 붙여넣은 뒤 그 자리에 이미지를 직접 넣으세요.
· Title/Body 텍스트 안에서 부분적으로 크기·색을 다르게 준 경우, 색상은 Figma 값 그대로 적용되고 크기는 아래 목록 중 가장 가까운 값으로 맞춰집니다.
